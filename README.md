# 📝 Simple Notepad (Qt C++)

A lightweight Notepad-like text editor built using the **Qt Framework** and **C++**.  
This project demonstrates basic file handling and text editing operations in a GUI application.

---

## 📌 Features
- Create new text files
- Open existing text files
- Save and Save As functionality
- Undo / Redo actions
- Cut, Copy, Paste operations
- Simple "About" dialog with app information

---
